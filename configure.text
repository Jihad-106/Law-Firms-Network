2. L3 SWITCH - L3_SW1
============================================================

enable
configure terminal

hostname L3_SW1

!
! Enable Layer 3 Routing
!

ip routing

!
! Routed link toward EDGE_R
!

interface GigabitEthernet1/0/1
 no switchport
 ip address 10.0.0.2 255.255.255.252
 no shutdown
exit

!
! Trunk toward Access Switch
!

interface GigabitEthernet1/0/2
 description TRUNK-TO-ACCESS-SW1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30,40,50,60,99
 no shutdown
exit

14. GUEST VLAN ACL
============================================================

!
! Goal:
! Guest VLAN 50 cannot access internal
! 192.168.x.x networks.
!
! Guest is allowed to reach 10.0.0.1.
!

ip access-list extended GUEST_RESTRICTION

 permit ip 192.168.50.0 0.0.0.255 host 10.0.0.1

 deny ip 192.168.50.0 0.0.0.255 192.168.0.0 0.255.255.255

 permit ip any any

exit


!
! Apply ACL inbound on Guest SVI
!

interface vlan 50
 ip access-group GUEST_RESTRICTION in
exit

17. TROUBLESHOOTING PERFORMED
============================================================

Problem 1:
PC could not communicate with Printer.

Checks performed:

show interfaces fa0/6 switchport
show interfaces trunk
show ip interface brief
show ip route

Root cause:
Layer 3 routing was not enabled on L3_SW1.

Solution:

ip routing
------------------------------------------------------------

Problem 2:
EDGE_R could not ping IP Phone 192.168.60.21.

Root cause:
EDGE_R did not have a route toward the Voice VLAN.

Solution:

ip route 192.168.60.0 255.255.255.0 10.0.0.2

After adding the route:

ping 192.168.60.21

Successful.


------------------------------------------------------------

Problem 3:
IP Phones received IP addresses but did not initially
receive expected phone connectivity.

Checks performed:

show ip dhcp binding

Verified:

192.168.60.x addresses were assigned.

Voice DHCP pool included:

option 150 ip 10.0.0.1

CME was configured on EDGE_R with:

ip source-address 10.0.0.1 port 2000


------------------------------------------------------------

Problem 4:
SSH connection timed out.

Troubleshooting approach:

1. Check VLAN 99
2. Check Management SVI
3. Check trunk
4. Check Management PC IP
5. Ping 192.168.99.1
6. Verify SSH configuration

SSH command:

ssh -l jihad 192.168.99.1
